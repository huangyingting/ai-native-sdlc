# ai-native-sdlc

Manually run **Copilot CLI call-chain demo** from **Actions → Copilot CLI call-chain demo → Run workflow**. Open the completed run's **Job Summary** to see the observed parent/subagent/model/tool hierarchy, timestamps, durations, parallel-agent peak, and token counts when emitted. Two independent subagents compare Amazon S3 with Azure Blob Storage: the AWS track must call built-in `web_search`, while the Azure track must call the public `microsoft-learn` MCP server's `microsoft_docs_search`. `--fleet` encourages parallel delegation but **does not guarantee any subagents or tool calls**. The summary flags missing tool calls or absent subagent overlap, and the renderer fails the job if this demo evidence is missing.

The workflow runs only with `workflow_dispatch`, installs Node 22 and `@github/copilot`, and authenticates with the run's short-lived `GITHUB_TOKEN` (`contents: read`, `copilot-requests: write`). The repository owner needs a Copilot entitlement and available usage; usage in a personal repository is billed to that owner's Copilot seat. Organization repositories additionally need the Copilot CLI organization billing policy. No PAT or repository secret is required.

The checked-in `.github/mcp.json` allows only two read-only tools on the public, unauthenticated [Microsoft Learn MCP server](https://learn.microsoft.com/en-us/training/support/mcp); the headless workflow opts in to loading this workspace MCP configuration. CLI OpenTelemetry writes JSONL to the runner's temporary directory; prompt/content capture remains disabled and the raw trace is **not uploaded**. The renderer accepts both direct CLI span records and OTLP `resourceSpans[].scopeSpans[].spans[]`, publishing only selected metadata to the Job Summary. A missing or malformed trace fails the renderer (which runs even if Copilot fails), rather than producing a fake call chain. The summary may contain public agent/tool/model metadata, so do not put sensitive material in this demo repository or prompt.

Run the local, dependency-free parser tests with `node --test scripts/render-trace.test.mjs`.
